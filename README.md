# Knacka

Dörrknackningsapp för Fiskaren.nu: karta med nålar, leads, återbesök, tävling och områden.
Byggd som en webbapp (läggs på hemskärmen) med Firebase för inloggning och gemensam data.

- `config.js` – Firebase-inställningar
- `firestore.rules` – säkerhetsregler, klistras in i Firebase → Firestore → Regler
